# 执行步骤 v1.0

> 更新日期：2026-06-10
> 当前阶段：项目初始化 — 文档体系搭建完成，待开始代码编写
> 技术栈：Kotlin + Jetpack Compose（复用 aitry_JARVIS 基础设施）

---

## 开发原则

1. **每阶段独立验收**：一个阶段完成并验证通过后，再进入下一阶段
2. **不一口气做太多**：每天聚焦 1-2 个模块，保持代码质量
3. **先骨架后血肉**：先建数据层和基础导航，再逐步填充功能和动效
4. **优先离线闭环**：核心功能完全离线可用，AI功能后续接入

## 阶段一：项目骨架 + 数据库（预计 1-2 天）

### 目标
搭建可编译运行的空白项目，创建所有数据库表和基础Repository。

### 步骤
1. **初始化 Gradle 项目**
   - 复制 aitry_JARVIS 的 `gradle/libs.versions.toml`、`build.gradle.kts`、`settings.gradle.kts`
   - 修改包名为 `com.usher.tactical`，项目名 `JARVIS-PT`
   - 创建 `app/build.gradle.kts`（引用 Compose + Room + Hilt）
   - Gradle Sync 通过 → assembleDebug 成功

2. **创建数据库层**
   - 创建 8 个 Entity：`HostEntity`, `HostAttributeEntity`, `ResourceEntity`, `TaskEntity`, `TaskCheckInEntity`, `TaskTemplateEntity`, `LockStatusEntity`, `SystemLogEntity`
   - 创建对应 DAO 接口
   - 创建 `Converters.kt`（JSON转换器）
   - 创建 `TacticalDatabase.kt`（Room + SQLCipher 加密）
   - 创建 DatabaseModule（Hilt DI）

3. **创建 Repository 层**
   - Domain 层：Repository 接口 + 领域模型
   - Data 层：Repository 实现

4. **创建基础 UI 骨架**
   - `TacticalApplication.kt`（@HiltAndroidApp）
   - `MainActivity.kt`（单Activity入口）
   - `ui/theme/` — 赛博朋克主题（Color, Type, Theme）
   - `ui/navigation/NavGraph.kt` — 路由定义（占位页面）
   - 底部导航壳（5个Tab占位）

### 验收标准
- [ ] `./gradlew assembleDebug` 构建成功
- [ ] 加密数据库创建成功（首次启动生成密钥）
- [ ] 数据库默认数据插入（host=usher, lock_status初始化）
- [ ] 5个底部导航Tab可切换

## 附：电脑母块程序（Python）

```python
# usher_mother_block.py
import pyotp
import sys

SEED = "USHER_TACTICAL_SEED_BASE32"  # 与手机端共享

def verify(token: str) -> bool:
    totp = pyotp.TOTP(SEED, interval=30)
    return totp.verify(token, valid_window=1)

if __name__ == "__main__":
    token = input("请输入动态令牌: ").strip()
    if verify(token):
        print(">> 验证通过。授权重新编译。")
    else:
        print("!! 验证失败。令牌无效或已过期。")
```
