## 一、项目定位

**宿主白厄·个人战术管理系统** —— 以游戏属性面板为顶层呈现、以手动签到硬核约束为底层驱动的个人单兵战术终端。

### 核心价值

> 成为白厄的"单兵战术终端"——一个记录、驱动、约束、指导其现实进化的硬核面板。

### 目标平台

- **仅 Android**（自用不上架应用商店）
- 最低 SDK 26（Android 8.0），目标 SDK 35（Android 15）

---

## 二、目标用户

| 用户群体 | 典型场景 | 核心诉求 |
|----------|----------|----------|
| 宿主白厄（唯一用户） | 每日体能训练、枪械练习、大型周期目标（如备战联赛） | 查看属性面板明确强弱项；手动签到获得成长正反馈；依靠锁死惩罚杜绝懈怠；AI参谋快速规划长期任务 |

## 三、核心功能模块（按优先级）

### P0 — 第一期必须完成

| 模块 | 功能点 | 简述 |
|------|--------|------|
| 宿主状态面板 | 身份与综合评分 | 固定显示宿主ID"白厄"，综合评分(70)，外圈呼吸灯效果 |
| 宿主状态面板 | 六维属性速览 | 力量/速度/体力/弹跳/排球技术/枪械，进度条+数值展示 |
| 宿主状态面板 | 体能/专项能力详情 | 分"排球方向"与"枪械战斗"子页，柱状图、列表、进度环 |
| 资源背包 | 四种资源展示 | 潜能点、专长点、通用经验、隐匿经验，网格布局 |
| 日常任务 | 每日刷新签到 | 预置"基础训练""枪械校准""状态维护"，分段签到 |
| 日常任务 | 完成归零逻辑 | 全部日常完成后失格计数器归零 |
| 主线/支线任务 | 子目标签到 | 多子目标（主线最多5个），独立签到，全部完成领取奖励 |
| 主线/支线任务 | 任务配置中心 | 手动创建日常任务/主线/支线，设定要求和奖励 |
| 惩罚锁死 | 失格计数器 | 隐藏计数，每日结算时有未完成日常则+1，全部完成归零 |
| 惩罚锁死 | 系统锁死UI | 计数器≥3触发，破碎玻璃效果覆盖，仅显示警告和编译按钮 |
| 惩罚锁死 | 双端重新编译 | 手机生成TOTP令牌 → 电脑母块验证 → 扣除20%经验+清潜能+降属性 |

| 数据备份恢复 | 自动备份+恢复 | 凌晨自动备份，保留3版，启动完整性检查 |

## 四、非功能需求

| 类别 | 要求 |
|------|------|
| 数据主权 | 所有数据仅存本地，不上传第三方云（AI调用仅发送脱敏目标描述） |
| 离线优先 | 核心闭环（任务、签到、奖惩、报告）完全离线运行 |
| 安全性 | 数据库 AES-256 加密(SQLCipher)，API Key 安全存储 |
| 硬核惩罚 | 锁死机制不可绕过，TOTP双端验证，惩罚永久不可撤销 |
| 性能 | 纯本地操作延迟 <100ms，图表渲染流畅 |
| 分发 | 自用不上架，ADB安装 |

---

## 五、数据库核心表（7张）

1. Host — 宿主信息（固定ID "usher"）
2. HostAttribute — 属性快照（分类、名称、数值、分项JSON）
3. Resource — 资源（潜能点、专长点、通用经验、隐匿经验）
4. Task — 任务（日常/主线/支线，支持父子节点）
5. TaskCheckIn — 签到记录
6. TaskTemplate — 任务模板
7. LockStatus — 锁死状态（计数器、是否锁死、上次结算时间）
8. SystemLog — 系统日志（不可变）

详见 [技术规范.md](技术规范.md) 数据模型章节。

## 六、第一期范围界定

第一期聚焦：**项目骨架 + 加密数据库 + 宿主属性面板 + 日常任务闭环 + 锁死惩罚系统**

不包括：
- AI 战术参谋（第二期集成）
- 战略报告图表（第二期集成）
- 日历联动（第三期）
- 资源消费/技能树（第三期）
