## 二、架构分层

```
┌──────────────────────────────────┐
│  UI Layer (Jetpack Compose)      │  ← 视图 + ViewModel
├──────────────────────────────────┤
│  Domain Layer                    │  ← 领域模型 + Repository接口
├──────────────────────────────────┤
│  Data Layer                      │  ← Repository实现 + DAO
├──────────────────────────────────┤
│  Core Layer                      │  ← Database + DI + Service + Utils
└──────────────────────────────────┘
```

### 数据流

```
Compose UI
  ↓ 用户操作
ViewModel (StateFlow<UiState>)
  ↓ 调用
Repository (Flow<DomainModel>)
  ↓ 调用
DAO (suspend fun)
  ↓ 执行
Room Database (SQLCipher 加密)
```

## 三、数据库规范

### 命名约定

| 对象 | 命名规则 | 示例 |
|------|----------|------|
| 表名 | 小写 + 下划线 | `host_attribute` |
| Entity类 | 大驼峰 + Entity后缀 | `HostAttributeEntity` |
| DAO接口 | 大驼峰 + Dao后缀 | `HostAttributeDao` |
| 主键 | `id`，UUID，TEXT类型 | `id TEXT PRIMARY KEY` |
| 时间戳 | `created_at`, `updated_at` | INTEGER (Unix timestamp) |
| 外键 | `{table}_id` | `host_id`, `task_id` |

### 约束规则

1. 所有表使用 UUID 主键，由应用层生成
2. 所有表包含 `created_at` 时间戳（SystemLog 除外，仅有 timestamp）
3. 外键用 `ON DELETE CASCADE`
4. LockStatus 是单行表，主键固定为 host_id

### 加密方案

```
首次启动 → 生成随机32字节密钥 → EncryptedSharedPreferences 存储
          → SQLCipher SupportOpenHelperFactory(passphrase) → Room.databaseBuilder
```

### 关键 SQL 表结构

```sql
-- Host: 宿主信息（单行）
CREATE TABLE host (
    id TEXT PRIMARY KEY DEFAULT 'usher',
    display_name TEXT NOT NULL DEFAULT '白厄',
    overall_score REAL NOT NULL DEFAULT 70.0,
    created_at INTEGER NOT NULL
);

-- HostAttribute: 属性快照
CREATE TABLE host_attribute (
    id TEXT PRIMARY KEY,
    host_id TEXT NOT NULL,
    category TEXT NOT NULL,      -- '体能' | '排球技术' | '枪械战斗'
    attr_name TEXT NOT NULL,     -- '力量' | '速度' 等
    value REAL NOT NULL,
    details_json TEXT,           -- 分项详情JSON
    updated_at INTEGER NOT NULL,
    FOREIGN KEY (host_id) REFERENCES host(id)
);

-- Task: 任务（支持父子节点）
CREATE TABLE task (
    id TEXT PRIMARY KEY,
    host_id TEXT NOT NULL,
    parent_id TEXT,             -- 主线子目标挂载
    type TEXT NOT NULL,         -- 'daily' | 'main' | 'main_sub' | 'side'
    name TEXT NOT NULL,
    requirement_json TEXT NOT NULL,  -- 要求配置
    reward_json TEXT NOT NULL,       -- 奖励配置
    status TEXT NOT NULL DEFAULT 'active',
    order_index REAL NOT NULL DEFAULT 0.0,
    due_date INTEGER,
    completed_at INTEGER,
    created_at INTEGER NOT NULL,
    FOREIGN KEY (host_id) REFERENCES host(id),
    FOREIGN KEY (parent_id) REFERENCES task(id) ON DELETE CASCADE
);

-- LockStatus: 锁死状态（单行）
CREATE TABLE lock_status (
    host_id TEXT PRIMARY KEY,
    disqualification_counter INTEGER NOT NULL DEFAULT 0,
    is_locked INTEGER NOT NULL DEFAULT 0,
    last_settlement INTEGER NOT NULL,
    FOREIGN KEY (host_id) REFERENCES host(id)
);
```

## 四、代码规范

### Kotlin 风格

- 遵循 Kotlin 官方编码规范
- 优先使用 `val`，仅在必要时使用 `var`
- 优先使用 `data class` 表示数据
- 使用 `sealed class`/`sealed interface` 表示 UI 状态
- 避免使用 `!!`，使用 `?.let {}` 或 `?:` 安全处理
- 协程在 `viewModelScope` 中启动

### Compose 规范

- 每个 Composable 函数职责单一
- 状态提升：状态在 ViewModel，事件回调上传
- 使用 `remember` 缓存计算结果
- `LazyColumn` 使用 `key` 参数确保稳定
- 自定义 Canvas 组件单独放 `ui/components/charts/`

### 命名约定

| 类型 | 约定 | 示例 |
|------|------|------|
| 类/接口 | 大驼峰 | `TaskRepository` |
| 函数/方法 | 小驼峰 | `getActiveDailyTasks()` |
| 属性 | 小驼峰 | `taskId` |
| 常量 | 全大写下划线 | `MAX_DAILY_TASKS` |
| Composable | 大驼峰 | `AttributeCard()` |
| 文件 | 大驼峰 | `DashboardScreen.kt` |

## 五、安全规范

1. **数据库加密**：SQLCipher AES-256，密钥存 EncryptedSharedPreferences
2. **API Key**：存 EncryptedSharedPreferences，不硬编码
3. **TOTP 种子**：存 Android Keystore，不落盘明文
4. **日志**：Release 构建关闭 DEBUG 日志，敏感信息不写 logcat
5. **备份**：每天凌晨自动备份加密数据库至私有目录，保留最近 3 版
