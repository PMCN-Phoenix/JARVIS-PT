# 设计规范 v1.0

> 来源：JARVIS-PTui设计稿.md
> 更新日期：2026-06-10

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| 赛博朋克/轻科幻 | 单兵战术终端视觉风格 |
| 数据直观 | 属性面板、进度条、图表，一屏掌握状态 |
| 操作硬核 | 手动签到确认，惩罚不可撤销，仪式感强 |
| 动效克制 | 关键节点有反馈，不过度干扰 |

---

## 二、全局视觉规范

| 要素 | 规范 |
|------|------|
| **设计风格** | 赛博朋克/轻科幻单兵战术终端 |
| **背景色** | #0A0A0F (极深蓝黑)，带微弱噪点纹理 |
| **主色调** | 青蓝色 #00E5FF (高亮操作、标题、图标) |
| **强调色** | 琥珀色 #FFB800 (签到按钮、奖励、完成状态) |
| **警告色** | 红色 #FF3D3D (锁死警告、惩罚文字) |
| **卡片背景** | #14141F (深灰蓝)，圆角12px，内阴影 rgba(0,229,255,0.05) |
| **卡片边框** | 0.5px rgba(0,229,255,0.15) |
| **主字体** | 系统默认无衬线，数字用等宽字体(JetBrains Mono) |
| **数字字体** | 属性数值等关键数字用等宽字体，字间距+2px |
| **字号层级** | 大标题 28sp / 卡片标题 18sp / 正文 14sp / 辅助文字 11sp |
| **底部导航** | 高度56px，背景 #0A0A0F，选中项青蓝色，未选中灰色 #555 |

## 三、色彩系统

```
主色调 (Primary):    #00E5FF  青蓝色 — 标题、图标、进度条、选中态
强调色 (Accent):     #FFB800  琥珀色 — 签到按钮、奖励、完成标记
警告色 (Error):      #FF3D3D  红色   — 锁死警告、惩罚文字
成功色 (Success):    #00FF88  绿色   — 编译完成、属性增长
背景色 (Bg):         #0A0A0F  极深蓝黑
卡片色 (Surface):    #14141F  深灰蓝
边框色 (Border):     rgba(0,229,255,0.15)
文字主色 (OnBg):     #FFFFFF
文字次色 (Secondary): #888888
文字辅助 (Tertiary):  #666666
```

## 五、页面布局规范

### 页面一：启动/验证页
- 背景纯黑 #000000
- 中央：战术头盔轮廓图标（青蓝色呼吸光效，1.5秒周期）
- 版本文字 "战术系统 v1.0" (11sp, #666)
- 终端文字逐行出现（打字机效果）：系统启动 → 身份验证 → 生物扫描 → 确认通过 → 欢迎回来
- 完成后 0.5秒自动跳转主仪表盘

### 页面二：主仪表盘（首页）
- **顶部宿主ID栏**：左 "// HOST: USHER" (14sp, 青蓝色)，右综合评分大字 (28sp, 青蓝色 + 呼吸环)
- **六维速览卡片**：属性名 | 横条进度条(高6px, 青蓝渐变) | 数值 (14sp等宽)
- **首要任务卡片**：任务名(18sp) + 子目标列表(复选框 + 文字 + 状态标签) + 进度条(琥珀色)
- **底部导航**：仪表盘 | 属性 | 任务 | 背包 | 日志

### 页面三：属性面板页
- 顶部标签切换：[体能] [排球技术] [枪械战斗]
- 体能子页：每属性一个卡片（32sp大数值 + 分项微型横条 + 趋势图标）
- 排球子页：基础技术横向柱状图（高48px，青蓝渐变）+ 进阶技术列表
- 枪械子页：专精等级大字 + 经验进度条 + 展开详情

### 页面四：任务中心页
- 顶部三标签：主线 | 支线 | 日常
- 右上角齿轮图标 → 任务配置中心
- 主线卡片：任务名 + 子目标(签到按钮+状态标签) + 提交按钮
- 日常列表：任务名 + 分段签到控件(时间型/数值型/百分比型)

### 页面五：任务配置中心
- 日常任务模板库列表（右滑编辑/删除）
- [+ 创建日常任务] 按钮 → 编辑器（名称/类型/目标值/奖励滑块）
- 战术参谋AI入口（琥珀色边框醒目按钮）→ 输入目标 → 生成草案 → 调整 → 激活

### 页面六：资源背包页
- 2列资产网格：
  - 潜能点 (黄色大数字) / 专长点 (蓝色大数字)
  - 通用经验 (白色大数字，可展开明细) / 隐匿经验 (暗色大数字)

### 页面七：战略报告页
- 顶部切换 [周报] [月报]
- 周报：环形图(完成率) + 六维雷达图(本周vs上周) + 事件时间线
- 月报：综合评分折线图(30天) + 属性堆叠柱状图(月初vs月末) + 系统评语

### 页面八：系统锁死页
- 覆盖层：破碎玻璃效果（半透明深色，裂纹图案，500ms扩散出现）
- 中央红色警告图标 + 警告文字 "宿主白厄连续3天未达最低作战标准" + "系统已锁死"
- 底部唯一按钮：[申请重新编译] (红色边框，白色文字)

### 页面九：重新编译页
- 顶部倒计时环(300→0秒，青蓝色)
- 中央6位动态令牌(36sp，等宽，格式 A7X-29K，30秒刷新翻转动画)
- 说明文字 + 验证通过后白色终端代码逐行出现(每行80ms间隔)
- 编译完成后自动跳转主仪表盘

### 页面十：系统日志页
- 顶部筛选栏：[全部] [签到] [奖励] [惩罚] [系统]
- 时间轴列表：时间戳(11sp灰色) + 内容(14sp白色) + 左侧色条(青蓝/琥珀/红色)
- 底部 [导出日志] 按钮

### 页面十一：设置/底层编译室
- 常规设置：API Key配置 / 母块种子配置 / 每日提醒时间
- 危险区域（红色边框包裹）：导出作战数据 / 手动触发系统锁死 / 完全重置系统

## 七、交互动效

| 场景 | 动效描述 |
|------|----------|
| 数值变化 | 属性值闪烁高亮300ms，绿色"+0.05"飘字向上浮动消失(800ms) |
| 签到按钮 | 点击后缩放至90%回弹(200ms spring)，变色为琥珀色 |
| 页面切换 | 底部导航切换：淡入淡出200ms |
| 锁死触发 | 破碎玻璃从中心扩散出现(500ms ease-out) |
| 令牌刷新 | 卡片翻动效果(300ms) |
| 编译代码 | 终端文字逐行出现，每行间隔80ms |
| 进度条 | 填充动画 ease-in-out 600ms |
| 呼吸环 | 透明度高低交替变化，2秒周期 |
| 启动文字 | 打字机效果逐字出现，每行完成停留0.5秒 |
